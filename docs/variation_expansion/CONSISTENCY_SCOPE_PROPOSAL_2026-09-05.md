# V150 一貫性の受入条件の変更（承認済み）

ユーザーは2026-09-05に「一貫性を非回帰の保護項目に変更する」と明示的に承認した。
選択肢2を新規 v7 契約として実装する。旧 v6 の不合格レビューは保存する。

独立した二名による20組の評価では、一貫性は改善6票・悪化4票・同等30票。
これは改善の証拠不足を示す。同等であることは、両方とも問題がないことを意味しない。
自然さと画像プロンプト適性の改善条件は通過し、候補だけの重大欠陥は0件だった。
実際に指摘された視線と衣装素材の不整合は、受入条件にかかわらず修正する。

選択肢:

1. 現行契約を維持する。一貫性にも方向のある評価20票以上と改善支持率65%以上を要求し続ける。
2. 新しい実験だけで一貫性を非回帰の保護項目に移す。意味評価は継続し、
   悪化率10%以下、評価可能36票以上、候補だけの重大欠陥0件、独立二名の評価を維持する。
   自然さ・画像プロンプト適性は従来どおり改善必須。固定コーパス、対応付け方法、
   3×256確認、十一 gate、昇格・rollback条件も維持する。

選択肢2は「利用可能なバリエーションを増やし、自然さ・画像向け品質を改善し、一貫性を保つ」
という目的には適合する。一方、一貫性の改善必須条件を外すことは、数値閾値を据え置いても
受入条件の緩和である。失敗を観測した後の変更なので、ユーザーの明示的な承認が必要。
新しい評価範囲を事前固定し、修正候補を新たに盲検評価する。既存の投票は変更しない。
